# Madison-Lowenstein-HSC-4933-final-poster-project

This repository contains the complete data processing pipeline, statistical analysis scripts, cleaned datasets, and visual outputs examining the relationship between neighborhood median household income, socioeconomic predictors, and adult obesity prevalence across  ZIP Code Tabulation Areas (ZCTAs) in Hillsborough County, Florida. 

Using 2024 CDC PLACES health datasets and U.S. Census Bureau American Community Survey (ACS) 5-year estimates, this project implements multivariate Ordinary Least Squares (OLS) regression  and geospatial choropleth mapping to identify structural drivers of local health disparities.
